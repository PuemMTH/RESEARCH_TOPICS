Visualizing the Web Search Results with Web Search Visualization Using Scatter Plot

ระบบ web search visualization ที่แสดงผลลัพธ์การค้นหาในรูปแบบ scatter plot ตาม last modification date และ document type ควบคู่กับ traditional list view เพื่อเพิ่มประสิทธิภาพการ explore ผลลัพธ์

Anwar Alhenshiri, Stephen Brooks, C. Watters, M. Shepherd IEEE Symposium on Web Society 2010 DOI: 10.1109/SWS.2010.5607488
Abstract & Contributions

ภาพรวม

!

ปัญหาที่ Paper นี้แก้

  • Traditional list-based search result presentation ไม่ user-friendly — ผู้ใช้ไม่สามารถ compare documents, filter, หรือ explore result space ได้อย่างมีประสิทธิภาพ
  • Search engines แสดงผลลัพธ์เรียง rank แต่ไม่มี visual overview ของ distribution ตาม properties ต่าง ๆ (เช่น temporal distribution, document type)
  • ผู้ใช้ต้องการ browse ผลลัพธ์ตาม dimension เพิ่มเติม เช่น freshness ของเนื้อหา
★

Key Contributions

  • Dual-view Presentation: แสดงผลลัพธ์พร้อมกันทั้ง traditional list view และ scatter plot view
  • 2D Scatter Plot Layout: X-axis = last modification date, Y-axis = document type — ทำให้ผู้ใช้เห็น temporal และ type distribution ของผลลัพธ์ได้ทันที
  • Interactive Filtering: ผู้ใช้สามารถ select region ใน scatter plot เพื่อ filter ผลลัพธ์ตาม dimension ที่ต้องการ

System Design

Architecture

Query → Search Engine API → Result metadata extraction (date, type) → Dual rendering: list view + scatter plot → Interactive selection → Filtered results

  • X-Axis (Temporal): last modification date ของ document — แสดง freshness distribution
  • Y-Axis (Type): document type (HTML, PDF, DOC ฯลฯ) — แสดง format distribution
  • Linked Selection: click/select ใน scatter plot → highlight ใน list view (และในทางกลับกัน)
2

Visualization Design Rationale

Design Choice

Scatter plot เลือก 2 dimensions ที่ user มักสนใจแต่ไม่ถูก expose ใน traditional list: temporal dimension (ต้องการ fresh vs. classic content) และ format dimension (ต้องการ PDF academic paper vs. HTML page)

Results & Benchmarks

Key Insights จาก Paper
  • Scatter plot view ช่วย user ค้นพบ patterns ใน result set ที่ list view ซ่อนไว้ (เช่น cluster ของ recent PDFs)
  • Dual-view approach ไม่ได้ replace list view แต่ complement — user ยังต้องการ ranking information จาก list
  • Document date และ type เป็น metadata ที่ extract ได้ง่ายและ useful สำหรับ visualization
ข้อสังเกต
  • Paper มาจากปี 2010 — บริบท web search เปลี่ยนไปมาก (search engines ปัจจุบัน rich snippets, AI summaries)
  • ไม่มี formal user study — evaluation เป็น descriptive/demonstration มากกว่า empirical
Gaps & Future Work

ข้อจำกัดและทิศทางต่อไป

Limitations
  • ใช้เพียง 2 dimensions (date + type) — อาจไม่ capture สิ่งที่ user จริง ๆ ต้องการ filter
  • ไม่มี user study วัด task completion time หรือ satisfaction
  • Context ปี 2010 — modern search engines เปลี่ยนไปมาก ทำให้ applicability ลดลง
  • Scatter plot coordinates ไม่ได้แสดง semantic similarity — documents ที่อยู่ใกล้กันไม่จำเป็นต้องเกี่ยวข้องกัน
Connection to My Research

ความเกี่ยวข้องกับวิทยานิพนธ์

What I Borrow

แนวคิด dual-view presentation (structured list + visual overview) เป็น UX pattern ที่ดีสำหรับ information retrieval systems — ถ้ามีระบบ browse scientific figures, scatter plot ตาม semantic dimensions อาจเป็น useful exploration tool

Where I Diverge

งานนี้เน้น metadata-based visualization (date, type) ซึ่งเป็น shallow properties; scientific figure retrieval ต้องการ semantic embedding-based visualization — t-SNE/UMAP บน figure embeddings จะ meaningful กว่ามาก

Open Questions

สำหรับ scientific literature visualization: dimension ไหนที่ useful สำหรับ exploring figure search results? (figure type, paper year, research domain, citation count?) — อาจ worth exploring ใน future work section
