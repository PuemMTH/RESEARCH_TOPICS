Key Contributions

  • 4-Level Query Taxonomy: จัดประเภท user queries เป็น Explicit Facts, Implicit Facts, Interpretable Rationales, Hidden Rationales — แต่ละระดับมีความซับซ้อนของ data interaction ต่างกัน
  • Technique-to-Level Mapping: สรุป challenge เฉพาะและ technique ที่เหมาะสมสำหรับแต่ละ query level
  • 3 Data Injection Strategies: เปรียบเทียบ context injection, small model, และ fine-tuning พร้อม trade-offs ที่ชัดเจน
  • Dataset Stratification Table: classify benchmark datasets ที่รู้จัก (HotPotQA, SQuAD, NQ ฯลฯ) ตาม query level

Datasets & Benchmarks

Results & Benchmarks

Dataset Stratification (เลือกตัวอย่าง)
  • Level 1 (Explicit): NQ, MS MARCO, TriviaQA, SQuAD, ASQA
  • Level 2 (Implicit): HotPotQA, 2WikiMultiHopQA, MuSiQue, StrategyQA, DROP
  • Level 3 (Interpretable Rationale): domain-specific (legal, medical guidelines)
  • Level 4 (Hidden Rationale): IT ops incident logs, code debugging histories
Insight สำคัญจาก Survey
  • Basic RAG เพียงพอสำหรับ Level 1 แต่ fail อย่างชัดเจนบน multi-hop reasoning (Level 2)
  • Chain-of-Thought + prompt tuning ช่วย Level 3 ได้มากแต่ไม่สามารถ extract hidden knowledge (Level 4)
  • Real-world applications มักมี mixed query levels → ต้องการ routing pipeline
Gaps & Future Work

ข้อจำกัดและทิศทางต่อไป

Limitations
  • Survey ไม่ได้ perform empirical experiments — เป็น taxonomy/framework เชิง conceptual
  • Boundary ระหว่าง Level 2 และ Level 3 ค่อนข้าง fuzzy ในทางปฏิบัติ
  • Context window limitation ยังคงเป็นปัญหา fundamental สำหรับ context injection strategy
  • Fine-tuning บน out-of-domain data อาจทำให้ LLM "ลืม" general knowledge — catastrophic forgetting
Future Directions
  • Multi-modal external data integration (text + image + table)
  • Automatic query level classification และ routing
  • Better evaluation metrics สำหรับ Level 3–4 queries
