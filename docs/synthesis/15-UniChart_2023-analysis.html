UniChart: A Universal Vision-language Pretrained Model for Chart Comprehension and Reasoning

โมเดล pretrained แรกที่ออกแบบมาเฉพาะสำหรับ chart comprehension ด้วย chart-specific pretraining objectives ครอบคลุมทั้ง low-level (data extraction) และ high-level (summarization, QA) tasks — ทำได้ state-of-the-art บน 4 benchmark พร้อมเร็วกว่า MatCha ถึง 11 เท่า

Key Contributions

  • UniChart pretrained model: Chart encoder + text decoder pretrained บน 611K diverse charts ด้วย 4 pretraining objectives ที่ออกแบบมาเฉพาะสำหรับ charts
  • Large chart pretraining corpus: 611K charts รวบรวมจาก multiple real-world sources (Statista, OWID, OECD, Plotly, SVG datasets) + data augmentation ด้วย D3.js และ Vega-Lite
  • Chart-specific pretraining objectives: (1) Data table generation, (2) Chart summarization, (3) Numerical & visual reasoning, (4) Open-ended QA
  • State-of-the-art บน 4 tasks: ChartQA, OpenCQA, Chart-to-Text (Pew & Statista), Chart-to-Table — พร้อมเร็วกว่า MatCha 11× ด้วย parameters น้อยกว่า 28%
  • Knowledge distillation สำหรับ chart summaries: ใช้ InstructGPT/ChatGPT สร้าง summaries สำหรับ charts ที่ไม่มี caption — เป็น scalable solution สำหรับ annotation

Model Architecture

Architecture

UniChart ใช้ encoder-decoder architecture: Donut encoder (ViT-based image encoder ที่ไม่ต้องการ OCR) + BART text decoder. Encoder รับ chart image โดยตรงและ encode เป็น sequence of patch embeddings. Decoder รับ task-specific prompt และ generate output text autoregressively.

  • Chart Image Encoder: ใช้ Donut encoder (ViT) — encode chart image เป็น visual token sequence โดยไม่ต้องผ่าน OCR engine ทำให้ end-to-end trainable
  • Text Decoder: BART-based decoder ที่รับ visual tokens จาก encoder + text prompt แล้ว generate output (answer, summary, data table)
  • Task prompting: แต่ละ task ใช้ prompt format ที่ต่างกัน เช่น "Summarize this chart:" สำหรับ summarization หรือ "What is...?" สำหรับ QA

Pretraining Objectives

  • Low-level: Data table generation — given chart image, generate underlying data table เป็น structured text. สอน model ให้ extract numerical values และ relationships
  • Low-level: Chart element extraction — extract specific chart components เช่น axis labels, legend items (annotation-based tasks)
  • High-level: Chart summarization — generate natural language summary จาก chart image. ใช้ knowledge-distilled summaries จาก LLM
  • High-level: Open-ended QA — answer free-form questions ไม่จำกัด vocabulary ใช้ ChartQA dataset เป็น training source

Gaps & Future Work

ข้อจำกัดและทิศทางต่อไป

Limitations
  • ไม่รวม surrounding text context: UniChart ใช้แค่ chart image — ไม่มี paper text, paragraph context, หรือ caption as input. สำหรับ scientific figure captioning ที่ต้องการ context จาก paper นี่คือ gap ใหญ่มาก
  • General charts ≠ Scientific figures: Corpus ส่วนใหญ่มาจาก news/statistics websites ไม่ใช่ scientific papers — ขาด complex multi-panel figures, domain-specific notation
  • ไม่มี personalization: ไม่รองรับ author-specific style หรือ domain adaptation — generate generic summary เหมือนกันสำหรับทุก chart
  • Evaluation metric จำกัด: BLEU-based metrics ไม่วัด factual accuracy หรือ completeness ของ generated summary
  • ไม่ ground output ใน evidence: ไม่มี mechanism ตรวจสอบว่า generated text ตรงกับ data จริงๆ ในกราฟ (hallucination risk)
Connection to My Research

What I Borrow

UniChart encoder architecture เป็น candidate สำหรับ vision encoder ใน RAG-based captioning system ของเรา — โดยเฉพาะ ViT-based Donut encoder ที่ไม่ต้องการ OCR และ pretrained tasks สำหรับ data table generation เป็น foundation ที่แข็งแกร่ง. Knowledge distillation approach (ใช้ LLM สร้าง labels) ก็น่าสนใจสำหรับ data collection

Where I Diverge

งานวิจัยของเรา เพิ่ม RAG context จาก paper (surrounding paragraphs, in-text mentions) ซึ่ง UniChart ไม่มี. นอกจากนี้เรา focus ที่ personalization ตาม author style ซึ่งไม่มีใน UniChart. Input ของเราคือ scientific paper figure ที่มี complex structure มากกว่า news charts ที่ UniChart ถูก pretrain มา

Research Gap

GAP หลัก: UniChart ไม่มี document context — ใช้ chart image อย่างเดียว. งานวิจัยของเราจะ address gap นี้ด้วยการ integrate RAG module ที่ดึง relevant text context จาก paper มาเป็น conditioning signal สำหรับ caption generation. การผสม UniChart encoder + RAG context + personalization คือ novel contribution
