MatCha: Enhancing Visual Language Pretraining with Math Reasoning and Chart Derendering

Google DeepMind pretraining approach ที่เพิ่ม Math reasoning และ Chart derendering objectives เข้ากับ Pix2Struct VLM — ทำให้โมเดลเข้าใจ numerical relationships ในกราฟได้ดีขึ้นอย่างมีนัยสำคัญ และ outperform prior SoTA บน PlotQA/ChartQA ถึง ~20%

Liu, Piccinno, Krichene et al. (Google DeepMind) ACL 2023 arXiv:2212.09662
Abstract & Contributions

ภาพรวม

!

ปัญหาที่ Paper นี้แก้

  • VLMs ไม่สามารถ reason เชิง numerical บน charts ได้: State-of-the-art VLMs อย่าง Pix2Struct ถูก pretrain บน screenshot parsing (HTML-based) ซึ่งไม่ต้องการ mathematical reasoning — ทำให้ fail บน chart questions ที่ต้องการ arithmetic
  • Chart derendering ยังทำได้ไม่ดี: การ extract underlying data table จาก chart image (reverse-engineering the visualization) ยังเป็น bottleneck ที่ทำให้ downstream tasks ทำได้ไม่ดี
  • ขาด chart-specific pretraining: General VLMs ไม่ได้ออกแบบมาสำหรับ chart domain โดยเฉพาะ ทำให้ transfer ไม่สมบูรณ์
★

Key Contributions

  • MatCha pretraining recipe: สองประเภทหลัก: (1) Chart derendering tasks (given chart image, generate data table/rendering code) และ (2) Mathematical reasoning tasks (given math question as image, decode answer)
  • Pix2Struct เป็น base: ต่อยอดจาก Pix2Struct (image-to-text VLM) และ fine-tune ด้วย chart + math data — ไม่ต้องออกแบบ architecture ใหม่
  • ~20% improvement: PlotQA V1: 90.2% (vs prior 73.2%), PlotQA V2: 73.9% (vs prior 56.0%), ChartQA: 64.2% (vs prior 56.5%)
  • Transfer to broader domains: ทดสอบบน screenshots, textbook diagrams, document figures — พบว่า MatCha pretraining improves performance ใน broader visual language tasks ด้วย
How It Works

Methodology

1

Base Model: Pix2Struct

Pix2Struct Architecture

Pix2Struct คือ image-to-text model ที่ใช้ ViT encoder (image patches → visual tokens) + T5-style decoder (autoregressive text generation). Key feature: image input ขนาดยืดหยุ่น (variable resolution) สำหรับ high-res document images. Pretrained บน screenshot-to-HTML parsing task จาก web pages.

2

Pretraining Task 1: Chart Derendering

  • Objective: Given chart image → decode underlying data table (หรือ rendering code เช่น Vega-Lite JSON)
  • Training data: ใช้ charts ที่มี ground-truth data tables จาก ChartQA, PlotQA, Statista datasets
  • สิ่งที่ model เรียนรู้: Layout understanding (bar heights → values), number extraction with correct magnitude, association ระหว่าง axis labels กับ data values
  • Key insight: Chart derendering เป็น comprehensive pretraining task เพราะต้องการทั้ง visual parsing และ structured output — เรียนรู้ chart structure โดยปริยาย
3

Pretraining Task 2: Math Reasoning

  • Objective: Given math question rendered as image → decode correct numerical answer
  • Training data: Math datasets (MATH, GSM8K) rendered as images — ทำให้เป็น visual task แทนที่จะเป็น text task
  • สิ่งที่ model เรียนรู้: Arithmetic operations (addition, subtraction, comparison), percentage calculations, multi-step reasoning
  • Synergy กับ chart task: Math reasoning เสริม chart derendering — เมื่อ model ทำ arithmetic บน math questions และ extract values จาก charts ก็สามารถตอบ chart QA ที่ต้องการ computation ได้

Gaps & Future Work

ข้อจำกัดและทิศทางต่อไป

Limitations
  • ไม่มี text generation objective: MatCha pretrain เฉพาะ data extraction และ QA — ไม่มี objective สำหรับ natural language generation (summarization, captioning) ทำให้ weak บน open-ended generation tasks
  • ไม่ใช้ surrounding text context: เหมือน UniChart — รับ chart image อย่างเดียว ไม่มี mechanism สำหรับ incorporate paper context
  • Large model (282M params): Slow inference เมื่อเทียบกับ UniChart (11× slower)
  • ไม่ address scientific figure specifics: Complex subfigures, multi-panel layouts, domain notation ไม่ได้ถูก address
  • Evaluation focus บน QA เท่านั้น: ไม่มีการวัด faithfulness หรือ factual correctness ของ generated text
Connection to My Research

ความเกี่ยวข้องกับวิทยานิพนธ์

What I Borrow

MatCha's chart derendering objective เป็น pretraining strategy ที่สำคัญ — ถ้าเราต้องการ pretrain หรือ fine-tune model สำหรับ scientific figure captioning เราสามารถใช้ derendering tasks (figure → data table) เป็น auxiliary objective ได้. นอกจากนี้ math reasoning pretraining ช่วยให้ model ตีความค่าตัวเลขในกราฟได้ถูกต้อง

Where I Diverge

MatCha focus ที่ QA (question → answer) ในขณะที่งานเราต้องการ captioning (figure → description). ที่สำคัญกว่าคือเราต้องการ incorporate paper context via RAG และ author style personalization ซึ่ง MatCha ไม่มี. Scientific figures ที่เราใช้ก็ complex กว่า general infocharts มาก

Research Gap

MatCha + RAG Context: ไม่มีงานที่ใช้ MatCha/Pix2Struct เป็น base แล้วเพิ่ม RAG module สำหรับ scientific figure captioning. Gap นี้เป็นโอกาสสำคัญ: ถ้าเรา fine-tune MatCha ด้วย (chart image + retrieved paper context) → caption เราน่าจะได้ทั้ง visual understanding จาก pretraining และ contextual accuracy จาก RAG
