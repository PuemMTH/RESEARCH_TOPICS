Pix2Struct: Screenshot Parsing as Pretraining for Visual Language Understanding

Google Research VLM foundation model ที่ pretrain ด้วยการ parse masked web screenshots เป็น simplified HTML — เป็น base architecture สำหรับทั้ง MatCha และ UniChart โดยนำเสนอ variable-resolution input และ end-to-end pixel-to-text pipeline ที่ทำได้ SoTA บน 6 จาก 9 tasks

Lee, Joshi, Turc et al. (Google Research) ICML 2023 arXiv:2210.03347
Abstract & Contributions

ภาพรวม

!

ปัญหาที่ Paper นี้แก้

  • Visually-situated language ต้องการ domain-specific solutions: งาน document QA, diagram understanding, UI captioning, chart QA ต่างก็ใช้ recipe เฉพาะของตัวเอง ไม่มี unified pretrained model ที่ handle ทั้งหมดได้
  • Fixed-resolution images ทำให้ข้อมูลสูญหาย: VLMs ทั่วไปปรับ image ให้เป็น fixed size (เช่น 224×224) ทำให้ข้อความใน charts/documents อ่านไม่ออกเพราะถูก downsample
  • Pretraining objectives ไม่ครอบคลุม visual understanding: Text-based pretraining (MLM) ไม่เรียนรู้ visual layout; image captioning ใน COCO style ไม่เพียงพอสำหรับ document understanding
  • OCR เป็น bottleneck: หลายระบบพึ่ง external OCR engine ทำให้ error propagate และไม่ end-to-end trainable
★

Key Contributions

  • Screenshot-to-HTML pretraining: Novel pretraining objective — given masked webpage screenshot, generate simplified HTML structure. Web pages เป็น supervision source ขนาดใหญ่มากที่มี visual elements + structured text
  • Variable-resolution input: แทน fixed 224×224, Pix2Struct resize image ให้ patch sequence มี length ≤ N patches โดยคง aspect ratio — ทำให้ handle high-res document images ได้โดยไม่ distort
  • Language prompts rendered on image: คำถามหรือ task instruction render ลงบน input image โดยตรง (ไม่แยก text input stream) — ทำให้ architecture เรียบง่ายขึ้น
  • SoTA บน 6/9 tasks: ครอบคลุม 4 domains — documents (DocVQA), illustrations (AI2D), user interfaces (Screen2Words, Widget Captioning), natural images (TextVQA, ST-VQA)
How It Works

Methodology

1

Architecture

Encoder-Decoder Pipeline

Pix2Struct ใช้ ViT encoder (image → patch embeddings) + T5-style autoregressive decoder (text generation). Input คือ image pixels เท่านั้น — ไม่มี OCR, ไม่มี separate text encoder. Task prompt render ลงบน image ก่อนส่ง encoder.

  • Variable-resolution patches: Image ถูก resize ให้จำนวน patches ≤ max_patches (e.g., 2048) โดยคง aspect ratio — high-res images ได้ more patches, low-res ได้ less
  • 2D position embeddings: แต่ละ patch มี (row, col) positional embedding แทน 1D sequence — ช่วย model เข้าใจ spatial layout
  • Warmup stage: Pretrain ด้วย text rendering ก่อน (render text เป็น image → decode) เพื่อ initialize model ให้รู้จัก text ใน image
2

Pretraining: Screenshot → HTML

  • Data collection: Crawl web pages, render เป็น screenshots, extract simplified HTML (remove CSS/scripts, keep structural tags)
  • Masking strategy: Mask rectangular regions ของ screenshot ก่อน feed เข้า encoder — model ต้อง infer ทั้ง visual content และ text structure ใน masked region
  • Scale: Pretrain บน millions of web pages — diverse domains (news, wiki, e-commerce, science pages)
  • Implicit OCR: เรียนรู้อ่าน text จาก image โดยปริยาย (ผ่าน HTML target) โดยไม่ต้องใช้ OCR supervision โดยตรง

Gaps & Future Work

ข้อจำกัดและทิศทางต่อไป

Limitations
  • Pretraining domain (web) ≠ scientific papers: Web pages มี structure ต่างจาก scientific figures — ไม่มี axis labels, legends, complex plot structures ใน pretraining data
  • ไม่รู้จัก numerical relationships: Screenshot parsing ไม่บังคับให้ model เข้าใจ mathematical relationships — นี่คือเหตุผลที่ MatCha ต้องเพิ่ม math reasoning objective
  • ยังเป็น image-only: ไม่มี mechanism รับ text context จาก surrounding document — ต้องการ multimodal fusion สำหรับ context-aware generation
  • Compute intensive: Variable-resolution ที่ high max_patches ต้องใช้ memory มาก — tradeoff ระหว่าง resolution กับ efficiency
Connection to My Research

ความเกี่ยวข้องกับวิทยานิพนธ์

What I Borrow

Pix2Struct เป็น foundational architecture ที่ MatCha และ UniChart ต่างก็ build บน — เราเข้าใจ baseline capability ของ encoder-decoder VLM ผ่าน paper นี้. Variable-resolution input เป็น key feature ที่สำคัญสำหรับ scientific figures ที่มี complex layouts และ small text labels

Where I Diverge

Pix2Struct ไม่มี chart-specific pretraining (นั่นคือ contribution ของ MatCha/UniChart) และไม่มี text context input. งานวิจัยของเราต้องการ multimodal input: figure image + retrieved paper context ซึ่งต้องการ architecture ที่รับ dual input (visual + textual) ต่างจาก Pix2Struct ที่ image-only

Research Gap

Evolution path: Pix2Struct → MatCha (+ math/chart) → UniChart (+ summarization, larger corpus) → งานเรา (+ RAG context, + personalization, + scientific figure domain). Gap ที่ยังไม่มีคือการรวม retrieved paper context เข้ากับ chart understanding model — นี่คือ novel contribution ที่เราจะทำ
