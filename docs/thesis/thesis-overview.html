02 · System Architecture

5-Module Pipeline

ระบบประกอบด้วย 5 โมดูลทำงานต่อเนื่อง ตั้งแต่รับ PDF ไปจนถึงสร้าง caption ขั้นสุดท้าย

1

Document Parsing & Layout Analysis

แยกองค์ประกอบจาก PDF — ภาพ, ข้อความ, ตาราง, caption พร้อม bounding boxes

2

Visual Understanding

จำแนกประเภทภาพ, ดึง OCR tokens, แปลงกราฟเป็นข้อมูล (chart derendering)

Context Extraction

ดึง mention-paragraphs, Section-aware context, Cross-reference resolution ผ่าน RAG

Multimodal Caption Generation

Quality Assessment & Refinement

Faithfulness checking, context relevance scoring, iterative self-correction

03 · Problem Space

Research Gaps

5 ช่องว่างที่งานวิจัยก่อนหน้ายังไม่ได้แก้ไข — สิ่งเหล่านี้คือ contribution หลักของงานนี้

Gap 01

Context Integration Gap

งานส่วนใหญ่ใช้เฉพาะ mention-paragraph แต่ไม่ได้ใช้ full document context (abstract, intro, methodology)

Gap 02

Multi-Figure Type Gap

งานส่วนใหญ่เน้น chart/graph แต่ยังขาดการรองรับ architecture diagrams, flowcharts, experimental setups

Gap 03

Non-English Gap

ชุดข้อมูลและโมเดลส่วนใหญ่เน้นภาษาอังกฤษ ยังไม่มีงานสำหรับเอกสารวิชาการภาษาไทย

Gap 04

End-to-End Pipeline Gap

ยังไม่มี pipeline ครบจาก PDF → Layout Analysis → Context Extraction → Caption Generation

Gap 05

Evaluation Gap

Metric แบบเดิม (BLEU/ROUGE) ไม่เหมาะ ต้องการ framework ที่วัด faithfulness + context relevance

04 · Methodology

แนวทาง Caption Generation

เปรียบเทียบ 4 แนวทาง — แนวทาง D (Hybrid RAG + VLM) คือที่เลือกใช้

แนวทาง รายละเอียด ข้อดี ข้อเสีย
A: Prompt-based LMM ใช้ LMM (GPT-4V, Gemini) + prompt ที่รวม visual + context ง่าย, โมเดลใหญ่ ต้นทุนสูง, reproduce ยาก
B: Fine-tuned VLM Fine-tune open-source (Qwen2-VL, LLaVA) บน SciCap+ ควบคุมได้, reproduce ได้ ต้องการ GPU, ข้อมูลเยอะ
C: Multi-LLM Pipeline หลาย LLM ทำงานร่วมกัน (แบบ MLBCAP) คุณภาพสูงมาก ซับซ้อน, ต้นทุนสูง
D: Hybrid RAG + VLM เลือก RAG ดึง context → ส่งให้ VLM สร้าง caption สมดุลดี, novelty สูง, open-source ต้องออกแบบ retrieval ดี

07 · Evaluation Plan

Planned Experiments

6 การทดลองเพื่อตอบคำถามวิจัยและแสดง contribution ของระบบ

EXP 01

Baseline Comparison

เปรียบเทียบ VLM ต่าง ๆ ระหว่าง image-only vs context-aware

EXP 02

Context Ablation

วัดผลกระทบของแต่ละ level ของ context ต่อคุณภาพ caption

EXP 03

Figure Type Analysis

ดูว่าโมเดลทำได้ดีกับรูปแบบไหน (chart, diagram, photo, flowchart)

EXP 04

RAG vs Full Context

เปรียบเทียบ retrieval-based context vs การส่ง full text

EXP 05

Human Evaluation

ให้ผู้เชี่ยวชาญประเมิน faithfulness และ informativeness

EXP 06

LLM-as-a-Judge

ใช้ LLM ประเมินคุณภาพแทน human เพื่อ scalable evaluation
