\section{Evaluation Results on Test Set}
\label{sec:eval_on_test_set}

\ours{} contains 1,000 charts in the validation set and 1,323 charts in the test set. By default, practitioners should evaluate their models on the validation set on their own, and the result is shown in Table \ref{tab:main_result}. Here, we present results on the test set, where ground truth answers are privately held.
