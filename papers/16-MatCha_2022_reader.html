MatCha: Enhancing Visual Language Pretraining with Math Reasoning and Chart Derendering

Google DeepMind เพิ่ม Math reasoning + Chart derendering objectives เข้ากับ Pix2Struct — ทำให้โมเดลเข้าใจ numerical relationships ในกราฟได้ดีขึ้นอย่างมีนัยสำคัญ และ outperform prior SoTA บน PlotQA/ChartQA ถึง ~20% — เป็น base model ที่ UniChart ต่อยอด

Liu, Piccinno, Krichene et al. (Google DeepMind) ACL 2023 arXiv:2212.09662
Abstract & Contributions

ภาพรวม

ปัญหาที่ Paper นี้แก้

  • VLMs ไม่สามารถ reason เชิง numerical บน charts ได้ — Pix2Struct ถูก pretrain บน HTML parsing ไม่ต้องการ arithmetic
  • Chart derendering (extract data table จาก image) ยังเป็น bottleneck สำหรับ downstream tasks
  • ขาด chart-specific pretraining — general VLMs transfer ไม่สมบูรณ์สำหรับ chart domain

Key Contributions

  • MatCha pretraining: สองประเภท — (1) Chart derendering (chart image → data table/Vega-Lite code) และ (2) Math reasoning (math question as image → answer)
  • Base: Pix2Struct: ต่อยอดจาก Pix2Struct — ไม่ต้องออกแบบ architecture ใหม่ แค่เพิ่ม domain-specific pretraining
  • ~20% improvement: PlotQA V1: 73.2% → 90.2%, PlotQA V2: 56.0% → 73.9%, ChartQA: 56.5% → 64.2%
  • Transfer: MatCha pretraining ช่วย broader visual language tasks — screenshots, textbook diagrams, document figures
How It Works

Methodology

Pretraining Task 1: Chart Derendering

Given chart image → decode underlying data table หรือ Vega-Lite rendering code. Model ต้องเรียนรู้ layout (bar heights → values), number extraction, axis-data association. เป็น comprehensive task เพราะต้องทั้ง visual parsing และ structured output generation.

Pretraining Task 2: Math Reasoning

Given math question rendered as image → decode correct answer. ใช้ MATH, GSM8K datasets ที่ render เป็น images. สอน model ทำ arithmetic, percentage, multi-step reasoning.

  • Synergy: Chart derendering สอน value extraction; math reasoning สอน arithmetic → ร่วมกันทำ chart QA ที่ต้องการ computation ได้
  • Ablation: Derendering alone: +10%; Math alone: +5%; Combined: +7.7% — synergistic แต่ไม่ additive เพราะ overlap บาง aspect

Gaps & Future Work

ข้อจำกัดและทิศทางต่อไป

  • ไม่มี text generation objective — weak บน open-ended summarization/captioning tasks
  • ไม่ใช้ surrounding text context — รับ chart image อย่างเดียว
  • Large model (282M params) — 11× slower than UniChart
  • ไม่ address scientific figure specifics: complex subfigures, multi-panel layouts, domain notation

What I Borrow

Where I Diverge

Research Gap
