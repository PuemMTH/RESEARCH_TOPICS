UniChart: A Universal Vision-language Pretrained Model for Chart Comprehension and Reasoning

โมเดล pretrained แรกที่ออกแบบมาเฉพาะสำหรับ chart comprehension ด้วย chart-specific pretraining objectives 4 ประเภท ครอบคลุมทั้ง data extraction และ summarization — ทำได้ SoTA บน 4 benchmarks พร้อมเร็วกว่า MatCha 11 เท่าด้วย parameters น้อยกว่า 28%

Masry, Kavehzadeh, Do, Hoque, Joty EMNLP 2023 arXiv:2305.14761
Abstract & Contributions

ภาพรวม

ปัญหาที่ Paper นี้แก้

  • General-purpose VLMs ไม่มี objective เฉพาะสำหรับ chart elements (bars, lines, axes, legends) — ไม่ "understand" chart อย่างที่ควร
  • MatCha pretrain เฉพาะ data table generation และ math reasoning — ขาด text generation objectives สำหรับ summarization
  • ไม่มี universal pretrained model ที่ handle chart tasks ได้ครบทุก task ใน unified framework

Key Contributions

  • UniChart pretrained model: Donut encoder + BART decoder, pretrained บน 611K charts ด้วย 4 chart-specific objectives
  • 4 Pretraining Objectives: (1) Data table generation, (2) Chart summarization, (3) Numerical & visual reasoning, (4) Open-ended QA
  • 611K chart corpus: Real-world sources (Statista, OWID, OECD) + SVG extraction + D3.js/Vega-Lite augmentation
  • Knowledge distillation: ใช้ InstructGPT/ChatGPT สร้าง summaries สำหรับ charts ที่ไม่มี caption
How It Works

Methodology

Architecture: Donut Encoder + BART Decoder

UniChart ใช้ Donut encoder (ViT-based image encoder ที่ไม่ต้องการ OCR) + BART text decoder. Chart image → visual tokens → decoder generate output text ตาม task-specific prompt. ไม่ต้องผ่าน OCR engine → end-to-end trainable.

Chart-Specific Pretraining

  • Low-level: Data table generation — given chart image, generate underlying data table เป็น structured text
  • High-level: Chart summarization — generate natural language summary (ใช้ knowledge-distilled summaries จาก LLM)
  • High-level: Open-ended QA — answer free-form questions ไม่จำกัด vocabulary

Gaps & Future Work

ข้อจำกัดและทิศทางต่อไป

  • ไม่รวม surrounding text context — ใช้แค่ chart image, ไม่มี paper paragraphs หรือ in-text mentions
  • Corpus ส่วนใหญ่มาจาก news/statistics websites — ไม่ใช่ scientific papers ที่มี complex multi-panel figures
  • ไม่มี personalization — generate generic summary สำหรับทุก chart เหมือนกัน
  • ไม่มี mechanism ตรวจสอบ factual accuracy (hallucination risk)
Connection to My Research

What I Borrow

UniChart encoder เป็น candidate สำหรับ vision encoder ใน RAG-based captioning system. Knowledge distillation approach (LLM สร้าง labels) น่าสนใจสำหรับ data collection ของ scientific figure captions

Research Gap

UniChart + RAG document context ยังไม่เคยถูก explore — การผสม UniChart encoder + retrieved paper context + author style personalization คือ novel contribution ของ thesis
