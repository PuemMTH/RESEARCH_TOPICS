Paper Analysis · ICCVW 2025

MIND-RAG: Multimodal Context-Aware and Intent-Aware Retrieval-Augmented Generation for Educational Publications

Framework ที่แก้ปัญหา multimodal RAG ใน educational publications ด้วย context-aware image summarization และ intent-aware reranking บรรลุ 84.29% accuracy บน MEED-QA benchmark

Jiayang Yu, Yuxi Xie, Guixuan Zhang et al. ICCVW 2025 · MRR Workshop pp. 4216–4223
Abstract & Contributions

ภาพรวม

ปัญหาที่ Paper นี้แก้

  • Multimodal RAG ทั่วไปล้มเหลวกับ domain-specific academic documents เพราะ off-the-shelf image captioning และ vision encoders ไม่เข้าใจ semantic structure ของ scientific figures
  • Educational publications มี dense domain vocabulary และโครงสร้าง figure/table ที่ซับซ้อน — context ของ image สำคัญมากกว่า visual content เพียงอย่างเดียว
  • ระบบที่มีอยู่ไม่สามารถ model user intent ในกรณีที่ query ต้องการ multimodal understanding ข้าม modalities

Key Contributions

  • Context-Aware Image Summarization: สร้าง semantic text summary ของแต่ละ figure โดยใช้ surrounding textual context (caption + surrounding paragraphs) แทนที่จะพึ่ง visual encoding เพียงอย่างเดียว
  • Multimodal Intent-Aware Reranking: วิเคราะห์ user query intent ข้าม content modalities และ educational categories เพื่อ rerank retrieved results ให้ตรงกับความต้องการจริง
  • MEED-QA Benchmark: evaluate บน dataset จาก educational journals ที่มีทั้ง text และ figure questions
How It Works

Methodology

1 · Context-Aware Image Summarization

Pipeline

แทนที่จะ encode image ด้วย vision model โดยตรง MIND-RAG ดึง surrounding text context (ย่อหน้าก่อน/หลัง, captions, section headings) มา summarize ร่วมกับ visual content เพื่อสร้าง text representation ที่ rich ขึ้น

  • แก้ปัญหา domain gap ของ generic vision encoders ใน scientific figures
  • ทำให้ text-based retrieval system สามารถ "เข้าใจ" figures ผ่าน textual proxy
  • Context window ครอบคลุม paragraph-level context รอบ ๆ figure ในเอกสาร

2 · Multimodal Intent-Aware Reranking

Reranking

หลัง initial retrieval ระบบวิเคราะห์ user intent เพื่อ rerank results โดยพิจารณา: (1) modality ที่ query ต้องการ (text vs. figure), (2) educational category (concept explanation, methodology, results comparison)

  • Intent classification ช่วย filter noise จาก retrieved results ที่ modality ไม่ตรง
  • Educational category awareness ทำให้ระบบ prioritize figure ที่ "ถูกประเภท" มากกว่าแค่ semantic similarity

3 · MEED-QA Benchmark

Dataset

Benchmark จาก educational journal articles ออกแบบมาสำหรับ multimodal QA ที่ต้องอ้างอิง figures และ text ร่วมกัน — ประเมินทั้ง QA accuracy และ retrieval quality (MRR)

Gaps & Future Work

ข้อจำกัดและทิศทางต่อไป

Limitations
  • Context-aware summarization พึ่งพา quality ของ surrounding text — ถ้า figure มี sparse context ประสิทธิภาพลด
  • แม้จะเป็น Workshop paper แต่มีความยาว 8 หน้า (pp. 4216–4223) และให้รายละเอียดการทดลองทั้ง single-hop, multi-hop และการเปรียบเทียบกับ Graph-RAG ครบถ้วน
  • การเปรียบเทียบยังจำกัดอยู่บน MEED-QA เท่านั้น — generalizability ไปยัง non-educational domains ยังต้องทดสอบเพิ่มเติม
Connection to My Research

ความเกี่ยวข้องกับวิทยานิพนธ์

What I Borrow

แนวคิด context-aware image summarization ตรงกับ LaMPCap/AuthorContext approach — ใช้ textual context รอบ figure แทนที่จะพึ่ง visual encoder ล้วน ๆ นี่คือ validation ว่า direction ของงานวิทยานิพนธ์ถูกทาง

Where I Diverge

MIND-RAG เน้น retrieval quality (MRR) สำหรับ QA system; งานของเราเน้น generation quality ของ caption text (BLEU/CIDEr) — evaluation space ต่างกัน แต่ underlying problem (multimodal context understanding) เหมือนกัน

Open Questions

Intent-aware reranking จะ apply กับ captioning ได้อย่างไร? "Intent" ของ figure caption อาจหมายถึง document section (methodology figure vs. results figure) — ควรลองใช้ section type เป็น conditioning signal
